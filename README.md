# CLuB-1962
Clothing company

## Club 1962 HQ (`index.html`)
A dashboard that replaces the Club 1962 Excel workbook: sales, inventory, expenses,
customers, marketing, suppliers, monthly plans and efficiency checks.

- **Online version** (saves to a shared database): https://claude.ai/artifact/8nPX6Cik4zxZDzRHR1r39d
- **Offline:** open `index.html` in a browser. Data is saved in that browser only.
  Click **Restore** and pick `data/club1962-backup.json` to load the starting data.
- **Export to Excel** rebuilds a workbook with the same sheets as the original.
